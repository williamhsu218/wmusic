# WMusic 1.0.9

版本 **1.0.9 (13)**，2026-10-20。

根据实际截图重整右侧播放面板与入口。

- 工具栏使用明确的右侧播放面板图标，底部队列按钮增加文字和开关状态；沉浸模式使用展开箭头。
- 页签、队列选项和关闭键放在同一行；清空队列移入选项菜单，保留确认步骤。
- 当前曲目使用内缩浅色圆角高亮，增加 Now Playing / Up Next 层级；长标题提供悬停提示。
- 歌词、队列、信息与频谱共用面板宽度，支持 300–420 点原生拖拽及辅助功能调整，关闭重开保留宽度。
- 修复频谱打开时点击队列，按钮已亮但内容未切换的问题；快捷键与工具栏行为保持一致。

保留 1.0.8 的启动扫描与其他交互优化。验证与正式安装结果见 [本轮记录](../../player/docs/audits/2026-10-20-playback-panel.md) 和 [VALIDATION.md](../../VALIDATION.md)。

下载 `WMusic-1.0.9-macos-arm64.zip`，正常退出旧版后解压安装。预编译包要求 **Apple Silicon、macOS 27+**，音频库已随包附带。应用启用 App Sandbox，采用 ad-hoc 签名，未经过 Apple 公证；其他 Mac 的首次启动及实际播放仍需对应机器验证。包内不含音乐、用户数据库或配置凭据，附带第三方声明、构建信息和 SHA-256 校验值。
