# 2026-10-20 启动扫描与 UI/UX 优化

依据用户指定 Google 文档的方案 A 及第二点六个方向实施。原方案只读快照、构建日志、测试记录与本轮界面证据位于 `.build-logs/startup-ux-20261020/`。

## 实现与分析

| 项目 | 核对结果与实现 |
| --- | --- |
| 启动扫描 | 已有曲库默认只读取 SQLite，不创建扫描任务、不枚举来源。新增 `library.scanOnLaunch`，默认关闭；空曲库且有已保存来源时仍自动首次扫描。无来源、重复开窗均跳过。Quick Rescan、首次添加来源、运行期间的 FSEvents 监听保留。离线变化由用户手动重扫，或主动开启启动扫描。 |
| 播放栏 | 左侧身份信息与单色音质胶囊，中间控制与宽幅进度条，右侧音量及辅助按钮。侧栏打开后播放栏仍占整窗宽度；悬停预览时间，拖动时本地持有位置，松手提交一次，切歌时拒绝旧拖动。完整音频参数仍由悬停说明与 VoiceOver 读取。 |
| 展开与全屏 | 两种入口复用同一播放页和队列/歌词/可视化标签。封面本身生成模糊环境色，无逐帧取色定时器；缩略图与大封面共享几何过渡。减少动态效果时关闭位移动画；减少透明度或增强对比度时使用纯色背景。 |
| 专辑卡片 | 单击封面立即打开，独立 Play 按钮原地播放。命令点击多选、方向键、Return、右键菜单、辅助功能播放动作保留。艺人页使用相同封面按钮。 |
| 详情页 | 专辑头随曲目表滚动收起，小窗口自动使用 80pt 紧凑头；保留原生曲目表的排序、多选、拖放与右键菜单。艺人专辑区改横向画廊，保存和恢复横向位置，并随文字尺寸和窗口高度调整。 |
| 导航与侧栏 | 前进/后退留在左侧，其余开关移到工具栏右侧。统一 Inspector 可切换歌词、队列、曲目信息；保留歌词搜索、字体、偏移、编辑、在线替换等能力。歌词按钮仅在歌词实际显示时高亮，队列有独立播放栏入口。 |
| 曲目表 | 使用自适应主题底色、轻微交替行、悬停与当前曲目强调，复用低频 PlayingBarsIndicator；选中态文字适配原生高亮，减少动态效果时暂停律动。更新仍保留行版本差异门控，仅额外处理可见行。 |
