# WMusic 1.0.7

版本 **1.0.7 (11)**，2026-10-20。

## 启动与曲库

已有曲库默认直接加载数据库，跳过启动全量遍历。Settings → Library 新增启动扫描开关，默认关闭；空曲库且已有来源时仍自动首次扫描。Quick Rescan、手动重扫和运行期间的文件变化监听保留。需要补查应用关闭期间的离线变化时，请手动重扫或打开启动扫描。

## 界面与交互

- 播放栏采用三段布局，中央控制和进度条加宽，音频参数收进单色胶囊；展开侧栏后仍占整窗宽度。
- 展开播放与全屏共用封面环境色背景，以及队列、歌词、可视化标签；适配减少动态效果、减少透明度和增强对比度。
- 单击专辑封面立即打开详情，独立播放按钮原地播放；专辑头随列表滚动收起，艺人专辑区支持横向浏览。
- 歌词、队列和曲目信息统一到侧栏，保留歌词编辑、搜索、偏移与定位。曲目表增加轻微交替行、悬停和正在播放提示。

同时包含此前本机版的恢复进度、退出期限，以及超时、取消、缓存和服务生命周期修复；保留单一 Icon Composer 图标与构建配置稳定性优化。

## 下载与验证

下载 `WMusic-1.0.7-macos-arm64.zip`，正常退出旧应用后解压安装。预编译包要求 **Apple Silicon、macOS 27+**；附带音频库无需另装 Homebrew。应用使用 ad-hoc 签名，启用 App Sandbox，未经过 Apple 公证；其他 Mac 的首次启动和播放兼容性需要对应机器验收。包内不含音乐、用户数据库或配置凭据，保留许可与第三方声明。

- UI 回归 1,138 项、最终专项 48 项、10 项受影响快照通过；此前异常路径审计 1,090 项通过。
- 独立合成音频沙盒验收启动开关、手动重扫、歌词定位、进度拖动与续播、全屏返回及退出恢复。
- 真实 NAS 断线、重连及其他机器播放未纳入本次验证。共享几何动画未作逐帧量化；原生最小窗口全流程尚未形成验收证据。
- 附件提供构建信息和 SHA-256 校验值；详细范围见 [UI/UX 审计](../../player/docs/audits/2026-10-20-startup-scan-ui-ux.md) 与 [验证记录](../../VALIDATION.md)。
