# WMusic 1.0.1

首个 GitHub Release，发布于 2026-10-09。应用版本为 **1.0.1 (2)**。

WMusic 是面向 macOS 的音乐播放器，基于 [Bòcan](https://github.com/bocan/bocan-music)，保留上游来源、许可和第三方声明。

## 主要内容

- 本地曲库与播放列表，支持 FLAC、APE、MP3 等音频格式。
- 关闭随机播放后，从当前歌曲在原列表的位置继续顺序播放；重新开启或重启应用后，队列顺序保持正确。
- 修复曲末循环中断、重复启动扫描和切歌信息闪烁等问题。
- 全窗口播放页提供大封面、歌曲信息和播放控制，右侧可切换实时队列与歌词；歌词支持大字展示、逐句高亮、平滑跟随、点击跳转，以及普通全文和无歌词状态。
- NAS Folders 支持通过 Finder 连接 SMB 共享，包括服务器根地址、内网 IP、Tailscale 地址与设备名；断线时保留曲库条目。
- 保留 Subsonic/OpenSubsonic 音乐服务入口，并采用新的 W 音符图标。
- 本机安装脚本固定安装到 `/Applications/WMusic.app`，保留上一版应用和安装前曲库的唯一回滚快照。

## 下载与安装

下载 `WMusic-1.0.1-macos-arm64.zip`，解压后将 `WMusic.app` 放入 `/Applications`。更新前正常退出旧版本，并备份旧应用与曲库。安装包不包含音乐文件、用户数据库或个人 API 凭据。

预编译包要求 **Apple Silicon、macOS 27+**。主程序声明的构建目标为 macOS 15，附带音频库实际要求 macOS 27；不能据此声称安装包支持 macOS 15。应用使用 ad-hoc 签名，未经过 Apple 公证，运行时无需 Homebrew。其他 Mac 的兼容性与首次打开流程尚未验收。

附件中的 `WMusic-1.0.1-SHA256SUMS.txt` 提供校验值；`WMusic-1.0.1-BUILD-INFO.json` 记录源码提交、构建环境、架构与依赖库最低系统版本。
