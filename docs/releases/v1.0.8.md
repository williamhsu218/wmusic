# WMusic 1.0.8

版本 **1.0.8 (12)**，2026-10-20。

继续修整 1.0.7 的启动扫描和六项界面交互。

- 专辑头部按实际高度差保留滚动余量，过滤视口高度变化，避免短列表收起回弹；展开与收起状态的播放、随机播放行为一致。
- 封面播放按钮仅在整张卡片悬停或键盘聚焦时显示；Command 点击封面或标题可多选。
- 展开播放采用局部缩放和淡入淡出；悬停进度预览使用时间标签，避免遮挡播放键。沉浸模式有独立退出按钮及更宽松留白。
- 侧栏使用全局坐标拖拽，并支持读出宽度和键盘调整；歌词移除重复标题和材质，队列可确认清空，音频信息紧凑换行。
- 曲目表按播放状态变化更新指示器，改善圆角高亮及悬停清理。
- 显式注册启动扫描默认关闭。已有曲库的例行启动扫描不再弹窗阻挡正常退出；首次建库、手动扫描及音频分析继续保留保护。

UI 回归 1,187 项及 10 项受影响快照通过，完成隔离合成音频与原生界面验收。正式安装完成，保留曲库、队列、历史和上一版唯一回滚。

下载 `WMusic-1.0.8-macos-arm64.zip`，正常退出旧版后解压安装。预编译包要求 **Apple Silicon、macOS 27+**，音频库已随包附带。应用启用 App Sandbox，采用 ad-hoc 签名，未经过 Apple 公证；其他 Mac 的首次启动及实际播放仍需对应机器验证。包内不含音乐、用户数据库或配置凭据，附带第三方声明、构建信息和 SHA-256 校验值。

验证范围与取舍见 [交互修整记录](../../player/docs/audits/2026-10-20-interaction-refinement.md) 和 [验证记录](../../VALIDATION.md)。真实 NAS 断线重连与其他机器兼容性未纳入本轮验收，动画未作逐帧性能量化。
