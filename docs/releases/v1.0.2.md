# WMusic 1.0.2

应用版本为 **1.0.2 (3)**，发布于 2026-10-09。

## 歌词浏览改进

- 全窗口播放页右侧可切换队列与歌词，保留大字歌词、当前句高亮和渐隐效果。
- 同步与普通歌词始终隐藏滚动条，支持在歌词或空白区域通过滚轮、触控板上下滚动，也可按住内容上下拖动。
- 手动浏览后暂停自动跟随，点击 Follow Lyrics 恢复当前句定位；普通歌词拖动不再产生文字选择高亮。
- 同步歌词点击仍可跳转播放位置，拖动阈值避免拖动误触跳转；统一自动跟随和手动定位，修复连续播放时的当前句居中偏移。

## 下载与安装

下载 `WMusic-1.0.2-macos-arm64.zip`，解压后将 `WMusic.app` 放入 `/Applications`。更新前正常退出旧版本，保留旧应用与曲库备份。本工作区使用 `script/install_local_app.sh` 安装，并维护上一正式版应用和安装前数据库的唯一回滚。

预编译包要求 **Apple Silicon、macOS 27+**。主程序声明的构建目标为 macOS 15，附带音频库要求 macOS 27。应用使用 ad-hoc 签名，未经过 Apple 公证；运行时无需 Homebrew，其他 Mac 的首次打开和兼容性尚未验收。安装包不包含音乐文件、用户数据库或配置凭据，保留上游许可及第三方声明。

附件 `WMusic-1.0.2-SHA256SUMS.txt` 提供校验值；`WMusic-1.0.2-BUILD-INFO.json` 记录源码提交、构建环境与依赖平台。
